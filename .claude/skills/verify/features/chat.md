# Chat

The user describes their ideal customer in the composer on the home page (`/`). Each message starts one agent job in the Celery worker. The answer streams back over SSE, and tool results fill a lead list. The URL becomes `/?s=<sessionId>`, and the conversation appears in the sidebar under "Chat recenti". An open chat has a header with its title, a status pill, the credits it used and one chip per list it produced (at most one Aziende and one Persone list). The list panel shows those lists as tabs.

## Sub-features

- `chat-send` sends a brief from the composer, or from a starter chip.
- `chat-stream` streams the assistant's answer while the user can stop it.
- `chat-session` makes the conversation addressable at `/?s=<id>` and lists it in the sidebar's `region "CHAT RECENTI"`.
- `chat-new` starts an empty conversation.
- `chat-home` is the start screen of a new chat (`/` with no `?s=`) for a project with no list, campaign or running search (otherwise `chat-home-data`): `heading "Chi vuoi raggiungere?"`, the composer with `button "Carica CSV"`, the mode selector `button "Cosa vuoi fare"` (text `Trova persone`, desktop only), the line `Il piano è gratis: fino a 100 crediti parte subito, oltre lo approvi tu`, `button "Invia"`, three starter chips, and three entry cards (`Trova persone`, `Arricchisci i tuoi dati`, `Trova e contatta`; desktop only). Modes: `Trova persone` and `Trova e contatta` send a chat message (the second also sends `goal: "campaign"` with the first message, so the agent ends on a campaign draft); `Arricchisci i dati` opens the CSV import and sends nothing. A chip sends its brief with the selected mode's goal (none in enrich mode). On a phone the selector and the cards are gone, the chips scroll sideways with short copy, the line reads `Il piano è gratis`, and a `Da fare` block follows.
- `chat-welcome` replaces the start screen for a user who finished onboarding and has not closed it: `heading "Chi vuoi raggiungere per primo?"`, a composer with only `button "Invia"` (no mode selector, no `button "Carica CSV"`), one `button` card per onboarding segment (`region`-less, under `DAI TUOI SEGMENTI`; when a segment was written in another language than the UI, the note `Questi segmenti sono scritti in un'altra lingua.` sits above the cards and the names stay as written, #646), and `region "Primi passi"` with `0 di 3` style progress, `button "Nascondi"` and three rows: `Crea il profilo di vendita` (`link "Vedi nel Cliente"`), `Crea la tua prima lista` (`button "Inizia"` focuses the composer) and `Collega una casella email` (`link "Collega"`). A card starts a find turn whose message is one line that names the segment, titled with the segment's name; the whole brief, filters included, goes to `chat_sessions.brief` for the agent. A card send that fails before its chat opens (another job runs, the segment changed since the page loaded with `CHAT.SEGMENT_GONE`, the queue is down, the network fails) leaves no line in the chat: a toast names the cause and the cards load again from the server. `Nascondi` sets `business_profiles.welcome_closed_at`, and the normal start screen returns for good. It also closes by itself once the profile and the first list with at least one row are done (an empty list does not count); the mailbox step does not keep it open. No credit amount appears in its copy. Data: `GET /v1/home/welcome`, `POST /v1/home/welcome/dismiss`.
- `chat-home-data` is the start screen when the active project has a list, a campaign (active or paused) or a running search, and the first-access Home is closed: the topbar path `<client> / Panoramica` with `button "Nuova chat"` (it puts the focus in the composer), `heading "Panoramica"` with the date and greeting under it, the composer and `button "Carica CSV"` (no mode selector, chips or cards), then `region "Da fare"` (`link` rows `Messaggi da approvare`, `Risposte per te`, or the line `Niente in attesa…` when both are zero; one row alone when only one is non-zero), `region "In corso"` (hidden when no search runs; a `progressbar` per search, `N di M passi`, `link "Apri la chat"` on desktop), the dashboard panels (#906, `GET /v1/home/stats`: a `term`/`definition` strip `LEAD`, `CONTATTI`, `MESSAGGI INVIATI`, `RISPOSTE`, `RISPOSTE POSITIVE` over `Ultimi 30 giorni, variazione rispetto ai 30 precedenti`, `region "Attività settimanale"` with one `image "Settimana del <d>: <n> messaggi inviati, <n> risposte"` per week of 8, `region "Funnel"` (`Lead`, `Contatti`, `Contattati`, `Hanno risposto`, `Positivi`) and `region "Attività"` with a link per recent event), `region "Liste recenti"` (a list of rows: owner initials, name, kind `Persone|Aziende|Arricchimento` with `N righe`, `N email verificate` or `—`, the update time; 5 rows on desktop, 3 on a phone, with the row count and the update time hidden) and `region "Campagne attive"` (rows with channel chips, `Attiva|In pausa`, `N inviati`, `N risposte` and the reply rate, replies / sent; 3 on desktop, 2 on a phone; none: the `Crea una campagna` call to action, which opens `/campaigns?list=<id>` with the hint list preselected). While the overview loads the same shell shows skeleton blocks with `aria-busy`. A chat session `/?s=<id>` never shows it. Data: `GET /v1/home/overview`.
- `chat-todo` is the phone-only `region "Da fare"` on the start screen: one `link` per open item, in order: `Messaggi da approvare` (count, campaign name, links to `/campaigns/<id>`), `Risposte da leggere` (count, links to `/inbox`), `Ricerca in corso` (spinner, session title, links to `/?s=<id>`). It is absent when nothing waits, and refreshes when a turn ends. Data: `GET /v1/home/todo`.
- `chat-campaign-draft` shows a `draft_campaign` tool call that made a draft as `link "Bozza campagna pronta <name> · N persone Apri"` to `/campaigns/<id>`, in place of the usual tool row. A failed call stays a `Bozza campagna` row with `Errore`.
- `chat-failure` shows what the user sees when the job fails, for example when no LLM key is set.
- `chat-draft` prefills the composer from `/?draft=<text>`, focuses it, sends nothing and drops `draft` from the URL. It also prefills when the URL changes from `/` to `/?s=<id>&draft=<text>` without a reload (the CSV import's redirect).
- `chat-header` is the page topbar: `navigation "Percorso"` with `link "Chat"` (to `/chats`) and the chat title as the current page, the chat title again as a screen-reader `heading` level 1, the status pill with a dot (`In corso`, `Piano da approvare`, `Serve una risposta`, `Errore in un passo`, `Ricerca non riuscita` when every search failed (#787), `Finita`) and `N crediti usati`.
- `chat-lists` shows one chip per linked list in `group "Liste di questa chat"`: `button "Aziende 31"` (with `aria-pressed`) for a list with rows, a plain `Persone in bozza` for the list of a plan waiting for approval.
- `chat-question` shows the agent's question as `region "<question>"` with `text "DOMANDA"`, one numbered `button "1 <label> <description>"` per option, `button "Salta"` and, when the turn called `remember`, a line `Ho salvato nella memoria: «…»` with `link "Vedi memoria"`.
- `chat-noresults` shows an empty company search as `region "Nessuna azienda rispetta tutti i filtri"`: a line `Questa ricerca non ha trovato aziende: non ho aggiunto nulla alla lista e non ti ho addebitato nulla…` (without the `non ti ho addebitato nulla` half when the message used credits), `list "Aziende rimaste dopo ogni filtro"` with one `listitem` per filter group, worded as prose (#260: `text "Con sede a Piemonte, Italy"`, `20–100 dipendenti`, `Con annunci aperti per Account Executive`, several values joined with `o`; `text "56.557"`; the group that left 0 is last and carries `aria-current="step"`). An empty Apollo people search reads `region "Nessuna persona rispetta tutti i filtri"`, `list "Persone rimaste dopo ogni filtro"` (`Che lavorano a …`, `In aziende da … dipendenti`, `Con ruolo …`) and `~N persone` on its alternatives, `text "COME VUOI PROCEDERE?"` and one `button "N <Senza il …> <description> ~M aziende"` per alternative (each drops one filter group). Once answered only the funnel stays.
- `chat-summary` shows each tool call as a row: `text "Ricerca aziende"`, the query, `text "31 aziende"`. `set_brief` and `ask_user` calls have no row. An `enrich_email`/`enrich_phone` row reads from one typed summary (`kind`, #530 #548 #549 #550 #562) and draws its state icon from it: a batch that found something shows the check (`2 email · 1 non trovata · 1 da riprovare`), one that found none the neutral dash and `0 email · 3 non trovate`, one that only failed the warning triangle and `3 ricerche non riuscite` (never `0 email`), one with no active source `2 ricerche non riuscite · nessuna fonte attiva`, nobody to search the neutral dash and `Nessuno da cercare`, and ids that match no row the error cross and `Nessuna riga corrisponde`. The admin transcript line (`/admin/chat-sessions/<id>`) shows the same icon and text. On a phone the result wraps inside the row.
- `chat-brief` shows `complementary "Brief"` (1280 px and wider, only while the list panel is closed): the Brief, Piano, Ricerca, Lista stepper, `heading "COSA HO CAPITO"`, `button "Modifica"` and the terms Chi, Aziende, Dove, Segnale, Email.
- `chat-steps` shows the plan the last job runs as `region "Passi del piano"`: `progressbar "Avanzamento"`, one `listitem` per stage (`image "Completato" | "In corso" | "In coda" | "Errore" | "Fermato"`, the label, `N di M` or `In coda`), `N crediti usati`, and `button "Ferma"` above the composer while the job streams.
- `chat-stop` (#260): `button "Ferma"` stops the job on the server (`POST /v1/jobs/{id}/cancel`), not just the stream. It turns into `button "Mi fermo…" [disabled]` until the job closes the stream; the turn ends with `Mi sono fermato come mi hai chiesto. Ti ho addebitato solo quello che avevo già trovato.`, the pill reads `Finita`, the job is `cancelled` and the assistant row `partial` with `terminal_code` `cancelled`. A failed request shows the toast `Non sono riuscito a fermare la ricerca. Riprova.` and the turn goes on.
- `chat-step-error` shows a failed stage as `image "Errore"` with `alert` text `<reason> Le N <persone|aziende|righe> mancanti non ti sono state addebitate.` (N = units minus done; an email or phone step reads `Le N persone senza email|telefono non ti sono state addebitate.`, #260), `button "Riprova"` and `link "Apri la lista com'è"` (the failed job's own list; latest turn only, hidden while a turn streams or the connection is lost). Once the run has stopped the steps show alone, as the error screen draws them: no card, bar or credits total. `Nuovo tentativo…` replaces `Errore` only on the stage the running turn retries (`retry_stage` on the `stages` frame). The header pill reads `Errore in un passo`.
- `chat-connection` shows `status "Connessione interrotta"`, an `alert` with the banner text and `button "Ricarica"`, and a disabled `textbox "Scrivi all'agente"` (placeholder `Riconnettiti per scrivere`) while the stream is cut. The store rejoins by itself; the banner goes when the stream is back.
- `chat-panel` shows the lists as `tab "Persone N"` / `tab "Aziende N"`, a meta line, `link "Apri lista completa"` and `button "Nascondi lista"`. Its rows use the list page's controls: `button "Escludi"` / `"Includi"`, `button "In target"` / `"Fuori target"` and the fit number with four segments (a menu `Perché questo punteggio` when the row has reasons).

## How to get to it (user POV)

- Choose `link "Nuova chat"` at the top of the sidebar. It opens `/` with an empty composer. On desktop the logo is not a link. Only the phone top bar has `link "Zenbree"`.
- Type in the composer and press Enter or `button "Invia"`.
- Choose one of the starter chips, for example `button "Agenzie di marketing a Milano che assumono SDR"` (on a phone the chip text is the short copy, `Agenzie di marketing che assumono SDR`).
- Choose a mode with `button "Cosa vuoi fare"` (menu items `Trova persone`, `Arricchisci i dati`, `Trova e contatta`) or an entry card. The `Trova e contatta` card selects its mode and focuses the composer; the `Arricchisci i tuoi dati` card and `button "Carica CSV"` open the import dialog.
- Choose a conversation `link "<title>"` in the sidebar's `region "CHAT RECENTI"` to reopen it at `/?s=<id>`.
- Finishing onboarding with a segment also starts a chat, at `/?s=<id>`.
- A link to `/?s=<id>&draft=<text>` opens that chat's composer with the text; the CSV import redirects there. Drive it with `goto`.
- On a list page, `link "Nata dalla chat Apri la chat"` opens the chat that produced the list. A CSV import (`Importa N righe` in [lists](lists.md)) also lands on its chat.
- In an open chat, a chip opens the panel on that list; `link "Apri lista completa"` opens `/lists/<id>`.

## Driving it with bin/browser

Preconditions:

- Sign in a seeded user who is past onboarding, as described in the README. A user who just chose `Salta per ora` sees the first-access Home (`chat-welcome`, `Chi vuoi raggiungere per primo?`), not the start screen the steps below wait on: `bin/browser click button "Nascondi"` once to close it for good (`chat-home`: `Chi vuoi raggiungere?`, as long as the project has no list). A chat that produced a list turns later `Nuova chat` screens into `chat-home-data`, which has `heading "Panoramica"` and no chips or cards.
- For a successful turn, export `DEEPSEEK_API_KEY` or `ANTHROPIC_API_KEY` before `bin/stack up`. `bin/stack doctor` then prints `llm: key present`. Without a key, only `chat-failure` can be driven: start that stack with `VERIFY_LLM=off bin/stack up`.
- The `worker` service is running, as `bin/stack doctor` shows.

- **Send.**
  1. `bin/browser fill textbox "Descrivi chi vuoi raggiungere" "agenzie di marketing a Milano"`
  2. `bin/browser click button "Invia"`
  3. `bin/browser wait-url "?s="`

  The user message appears in `main`. The sidebar's `region "CHAT RECENTI"` gains `link "<first 80 chars of the brief>"` at the top with no reload: the sidebar follows `GET /v1/home/nav/stream`. It lists the newest 8 chats and no `link "Tutte le chat"`: `link "Chat"` (to `/chats`) opens the full list.
- **Start screen.** On a project with no list, campaign or running search (else the screen is `chat-home-data`, headed `Panoramica`), `bin/browser click link "Nuova chat"`, then `bin/browser wait text "Chi vuoi raggiungere?"`: `ax` shows the composer, `button "Carica CSV"`, `button "Cosa vuoi fare"`, three chips and three cards.
