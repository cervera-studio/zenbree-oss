# Lists

Results of chats live on Liste (`/lists`) and one page per list (`/lists/<id>`). The index shows each list with its type, delivered rows, source chat and creation time. The detail page holds the rows: tabs, search, a row aside, ratings, the AI column dialog and the export dialog. There is no mock: the screens read the API. The sample data is a database seed, `dev/seed/lists.sql`, which `bin/stack up` runs in the stack's own `postgres` container. It creates `dev@zenbree.local` / `zenbree-dev-1234` with 6 lists (457 rows) and their chats, and skips whatever is already there. Any other user, for example one from `bin/stack seed-user`, sees the empty state.

## Sub-features

- `lists-seeded` is the dev user's view: six lists, rows, AI columns with sources.
- `lists-empty` is any other user: the empty state.
- `lists-index` shows the table, the empty state and the phone cards.
- `lists-detail` shows the header, KPIs, `Stessa chat:` chips, tabs with counts and the search.
- `lists-more-rows` opens `Altre righe`: batch, credit ceiling, balance, then the chat with the request drafted.
- `lists-aside` opens a row's detail aside on a name click, closes it with Escape and toggles `Escludi` / `Includi`.
- `lists-rate` toggles `In target` / `Fuori target` on a row.
- `lists-export` opens the export dialog: format, rows, columns, the CTA count, then `File pronto` with `Scarica di nuovo`.
- `lists-ai-column` adds an AI column.
- `lists-delete` deletes a list from the index and an AI column from its header, each with the `Annulla` toast (#341).
- `lists-phone` shows the card list, the bottom sheet and the fixed `Esporta` / `Avvia campagna` bar below 760 px.
- `lists-not-found` shows the 404 page `Questa lista non esiste più` for an unknown id.
- `lists-import` is a CSV import on the real path.
- `lists-select` checks rows: `checkbox "Seleziona <nome>"` on each row and phone card, `checkbox "Seleziona tutte le righe visibili"` in the header, and `toolbar "Azioni sulle righe selezionate"` with `<n> selezionate` and `button "Annulla selezione"`.
- `lists-bulk-campaign` is `button "Aggiungi a campagna"` in the bar (person lists only): `dialog "Aggiungi a campagna"` with the draft campaigns as radios, then the result with one line per skip reason.
- `lists-bulk-off-target` is `button "Segna fuori target"` in the bar: the rows read `Fuori target` at once, and the toast has `button "Annulla"`.
- `lists-fit-chip` is `button "Fit oltre <n>"` (`aria-pressed`) beside the search: only rows scored `<n>` or more stay. `<n>` is 80, or the floor of the saved view the link opened (`?fit=<n>`).

## How to get to it (user POV)

- Choose `link "Liste"` in the sidebar. It opens `/lists`.
- Choose a list name in the table. It opens `/lists/<id>`.
- On the detail page choose `button "Esporta"`, `button "Colonna AI"` or a person's name.
